# Seeds of Hope - newsletter artwork

Artwork for the HTML / email edition of Unity Hospice's *Seeds of Hope* bereavement
newsletter. The emailed newsletter loads these pictures from this repository's GitHub Pages
URLs, so **renaming or deleting this repository breaks the pictures in every newsletter
already sent and every one still to come.** Leave it be.

Source of truth for the files is the project folder (`.../html/assets/`); this copy is
refreshed by `scripts/publish_assets_github.py`. No personal information is stored here - the
files are the printed newsletter's illustrations.
